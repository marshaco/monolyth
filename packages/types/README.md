TypeScript types for the monolyth API, generated from FastAPI's OpenAPI schema, so the frontend can't drift from the backend.

- `openapi.json`: the API schema, exported from `apps/api`
- `src/api.d.ts`: generated by `openapi-typescript`. Don't edit it by hand.
- `src/index.ts`: re-exports plus friendly aliases (`Holding`, `HoldingCreate`, `FilingSummary`)

Regenerate after changing any API route or Pydantic model:

```bash
uv run python apps/api/scripts/export_openapi.py   # from the repo root
cd packages/types && npm install && npm run generate
```

`apps/api/tests/test_openapi.py` fails if `openapi.json` is out of date with the API.

In `apps/web`, import them with `import type { Holding } from '@monolyth/types'`. The alias is in `apps/web/tsconfig.json`.
